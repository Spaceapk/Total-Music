# Total Music

Reproductor de música para Android mantenido por Spaceapk.

## Descargar Total Music 1.7.0 — Visual Experience

[Descargar la versión más reciente](https://github.com/Spaceapk/Total-Music/releases/latest) · [Historial de lanzamientos](https://github.com/Spaceapk/Total-Music/releases)

En el lanzamiento, abre **Assets** y descarga **Total-Music-1.7.0-universal.apk**. APK universal con firma permanente y paquete `org.nexlibre.totalmusic`; actualizable desde la versión oficial 1.6.0. Android 8 o posterior.

La versión 1.7.0 incorpora reproductores Original, Google Expressive+ y Liquid Glass+, efectos opcionales y seis widgets con apariencia automática o independiente. Conserva el ecualizador, AMOLED, colores de carátula y navegación adaptable.

Verificación: 1.101 pruebas aprobadas, una omitida y firma comprobada. Las pruebas en teléfono y las mediciones de rendimiento siguen pendientes. El lanzamiento incluye sumas SHA-256 e informe de verificación.

## Código fuente y desarrollo

Este es el repositorio principal de Total Music y conserva el historial original. Para el código completo de 1.7.0, descarga **Total-Music-1.7.0-source.zip** y su parche desde el lanzamiento. Los commits de implementación todavía están pendientes de transferencia a la rama remota; `main` conserva el código de 1.6.0. Los archivos automáticos de código fuente asociados a la etiqueta no sustituyen al ZIP adjunto de 1.7.0.
