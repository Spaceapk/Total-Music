# Total Music

Reproductor de música para Android mantenido por Spaceapk.

## Descargar

[Descargar Total Music 1.4.1](https://github.com/Spaceapk/Total-Music/releases/tag/v1.4.1)

APK universal con firma permanente y paquete org.nexlibre.totalmusic. Tema Google Expressive, colores de carátula opcionales, navegación Liquid Glass adaptable, modo oscuro negro puro y ecualizador de 10 bandas con modo avanzado de 31 bandas.

## Desarrollo

Este es el repositorio principal de Total Music. La rama main contiene la base migrada de la versión 1.2.0 y conserva el historial original.

- [Versiones y firma](docs/TOTAL_MUSIC_RELEASES.md)
- [Mantenimiento](AGENTS.md)
- [GitHub Actions](https://github.com/Spaceapk/Total-Music/actions)

[My-Music](https://github.com/Spaceapk/My-Music) permanece como respaldo y conserva los registros originales de compilación.
